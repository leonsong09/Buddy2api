# Buddy2api v2.2.13

发布日期：2026-10-31

小版本：按账号优先级选择别名通道，支持账号配置批量保存，并补齐账号重试和模型路由日志。对应 [#127](https://github.com/wicm84266964/Buddy2api/issues/127)。

## 别名路由

- 自动通道 API Key 请求裸别名或 `auto` 时，在匹配通道中比较启用账号的最高优先级，数字越大越优先；相同优先级保持原通道顺序。
- 绑定通道的 Key 和显式 `通道/模型` 请求继续使用指定通道。
- 各通道的别名仍需分别配置。

## 账号配置与重试

- 账号列表增加「保存全部修改」，保存所有编辑过的账号，包括筛选后隐藏的行。失败项保留修改供重试。
- 单条保存保留其他账号尚未保存的编辑。
- 可重试请求的尝试预算覆盖该通道的整个账号池，不再最多尝试三个账号。TraeWork 为每个账号保留一次凭据续期后的重试机会。
- 各通道原有的不可重试错误和流式输出后的停止规则继续生效。

## 请求日志

- 新请求记录客户端请求的别名、选中的通道和解析后的真实模型；首页最近请求和日志页显示映射关系。
- 支持按真实模型搜索日志；Chat Completions 和 Responses 都记录映射。

## 升级说明

- 启动时自动为日志表增加 `resolved_model` 字段，保留旧日志，旧记录不补填映射。
- 更新后重启服务并刷新管理页。
- 本地完整测试 511 项通过，覆盖 WorkBuddy / Qoder 流式和非流式请求在前四个账号失败后使用第五个账号。
- 正式版发布成功后推送 `ghcr.io/wicm84266964/buddy2api:v2.2.13`（`linux/amd64`），并移动 `latest`。
